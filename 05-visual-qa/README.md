# Visual QA — SID.DEV.BR

## Objetivo

Demonstrar validação visual de interface, responsividade, alinhamento, contraste, hierarquia visual, consistência de componentes e experiência de navegação usando o site `sid.dev.br` como laboratório de QA.

## Sistema testado

- Nome: SID.DEV.BR
- Tipo: Portfólio profissional
- URL pública: https://sid.dev.br
- Ambiente local: http://localhost:5520
- Foco: interface, layout, responsividade e padronização visual

## Escopo

- Hero principal
- Menu
- Botões
- Seção Portfólio QA
- Cards
- Tipografia
- Contraste
- Responsividade
- Fundo com partículas
- Orbe visual
- Rodapé

## Competências demonstradas

- Visual QA
- Testes exploratórios visuais
- Responsividade
- Usabilidade básica
- Padronização de interface
- Documentação de inconsistências visuais
- Critério estético aplicado à qualidade de software
