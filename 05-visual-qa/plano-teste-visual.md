# Plano de Teste Visual — SID.DEV.BR

## 1. Objetivo

Validar se o site SID.DEV.BR mantém consistência visual, legibilidade, responsividade e alinhamento com o novo posicionamento profissional voltado para QA.

## 2. Escopo incluído

- Verificar se o hero comunica corretamente o posicionamento profissional.
- Verificar se os botões mantêm padrão visual.
- Verificar se não existem bolinhas, orbes ou elementos indevidos nos botões.
- Verificar se as partículas continuam visíveis e em movimento.
- Verificar se o orbe principal foi preservado.
- Verificar se os cards da seção QA estão alinhados.
- Verificar legibilidade em desktop e mobile.
- Verificar contraste entre texto e fundo.
- Verificar espaçamento entre seções.
- Verificar se o menu não cobre conteúdo.

## 3. Fora do escopo

- Testes de backend.
- Testes de banco de dados.
- Testes de autenticação.
- Testes de carga.
- Testes ofensivos de segurança.

## 4. Ambientes

- Desktop
- Notebook
- Mobile via DevTools
- Navegadores: Chrome, Edge e Firefox
- Localhost: http://localhost:5520
- Produção: https://sid.dev.br

## 5. Critérios de entrada

- Site carregando sem erro.
- Versão QA visualmente aprovada disponível.
- Partículas e orbe preservados.
- Seção QA criada.
- Menu com item QA.

## 6. Critérios de saída

- Checklist visual preenchido.
- Inconsistências documentadas.
- Evidências registradas.
- Relatório visual atualizado.
