# Checklist Visual QA — SID.DEV.BR

## Hero

- [ ] Nome visível e legível.
- [ ] Linha profissional correta.
- [ ] Texto de apresentação coerente com QA.
- [ ] Botões alinhados.
- [ ] Botões com mesmo padrão visual.
- [ ] Botões sem bolinha/orbe indevido.
- [ ] Espaçamento adequado entre textos e botões.

## Menu

- [ ] Menu visível.
- [ ] Item QA presente.
- [ ] Links internos funcionando.
- [ ] Menu não cobre conteúdo ao navegar.
- [ ] Menu permanece legível sobre o fundo.

## Fundo visual

- [ ] Partículas visíveis.
- [ ] Partículas em movimento.
- [ ] Orbe principal preservado.
- [ ] Fundo não prejudica leitura.
- [ ] Elementos visuais não bloqueiam cliques.

## Seção Portfólio QA

- [ ] Título da seção legível.
- [ ] Descrição coerente com QA.
- [ ] Cards alinhados.
- [ ] Cards com espaçamento consistente.
- [ ] Tags legíveis.
- [ ] Conteúdo dos cards sem excesso de texto.
- [ ] Visual compatível com o restante do site.

## Responsividade

- [ ] Desktop 1920px.
- [ ] Notebook 1366px.
- [ ] Tablet 768px.
- [ ] Mobile 390px.
- [ ] Sem corte de texto em mobile.
- [ ] Sem sobreposição de botões.
- [ ] Cards reorganizados corretamente.

## Contraste e legibilidade

- [ ] Texto principal com contraste suficiente.
- [ ] Links visíveis.
- [ ] Botões destacados.
- [ ] Tamanho de fonte confortável.
- [ ] Hierarquia visual clara.

## Rodapé

- [ ] Informações de contato corretas.
- [ ] Links funcionais.
- [ ] Espaçamento preservado.
- [ ] Visual consistente com o restante do site.
