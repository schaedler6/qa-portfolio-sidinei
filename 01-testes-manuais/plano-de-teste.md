# Plano de Teste — SID.DEV.BR

## 1. Objetivo

Validar se o site sid.dev.br apresenta corretamente o posicionamento profissional de Sidinei Schaedler para QA, testes de software, automação e cibersegurança defensiva.

## 2. Escopo

### Incluído

- Carregamento da página inicial.
- Exibição correta do hero.
- Funcionamento do menu principal.
- Funcionamento dos botões principais.
- Exibição da seção Portfólio QA.
- Validação de textos principais.
- Validação visual básica.
- Validação de responsividade.
- Validação de links externos.

### Fora do escopo

- Testes de backend.
- Testes de banco de dados.
- Testes de autenticação.
- Testes de carga.
- Testes de pagamento.

## 3. Ambiente de teste

- Sistema operacional: Windows 10/11
- Navegadores: Chrome, Edge e Firefox
- Dispositivos: Desktop e visualização responsiva via DevTools
- URL local de teste: http://localhost:5520
- URL pública: https://sid.dev.br

## 4. Critérios de entrada

- Site carregando sem erro.
- Arquivos principais disponíveis.
- Menu e hero visíveis.
- Seção QA criada.
- Partículas, orbe e botões preservados.

## 5. Critérios de saída

- Casos de teste executados.
- Bugs relevantes documentados.
- Evidências registradas.
- Relatório de execução preenchido.

## 6. Riscos

- Cache do navegador exibir versão antiga.
- Alterações visuais afetarem partículas, orbe ou botões.
- Links externos indisponíveis temporariamente.
- Diferença visual entre ambiente local e GitHub Pages.
