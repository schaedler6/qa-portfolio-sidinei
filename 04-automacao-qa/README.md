# Automação para QA

## Objetivo

Demonstrar scripts simples para apoiar rotinas de QA, validação de links, checagem de status HTTP, organização de evidências e geração de relatórios.

## Tecnologias utilizadas

- Python
- PowerShell
- Markdown
- Git/GitHub

## Scripts criados

### Python

- `validar_links_site.py`  
  Valida uma lista de links e retorna status HTTP.

- `gerar_relatorio_testes.py`  
  Gera um relatório Markdown simples a partir de casos de teste simulados.

### PowerShell

- `checar_status_http.ps1`  
  Verifica status HTTP de URLs importantes.

- `organizar_evidencias.ps1`  
  Cria estrutura padronizada de evidências por data e tipo de teste.

## Competências demonstradas

- Automação básica para QA
- Organização de evidências
- Validação de links
- Relatório técnico
- Uso de Python e PowerShell em contexto de testes
