# Plano de Automação para QA

## Objetivo

Criar scripts simples para reduzir trabalho manual repetitivo em validações de QA.

## Escopo

### Incluído

- Validação de links.
- Checagem de status HTTP.
- Organização de evidências.
- Geração de relatório Markdown.

### Fora do escopo

- Testes automatizados E2E completos.
- Selenium, Cypress ou Playwright.
- Testes de carga.
- Integração CI/CD.

## Ambiente

- Windows 10/11
- PowerShell 7+
- Python 3.10+
- Git

## Critérios de sucesso

- Scripts executam sem erro.
- Relatórios são gerados corretamente.
- Estrutura de evidências é criada automaticamente.
- Código é simples, legível e documentado.
