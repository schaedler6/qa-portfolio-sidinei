# Bug Reports — SID.DEV.BR

## Objetivo

Demonstrar documentação profissional de defeitos, inconsistências e melhorias encontradas durante a validação do site `sid.dev.br`.

## Sistema testado

- Nome: SID.DEV.BR
- Tipo: Portfólio profissional
- URL pública: https://sid.dev.br
- Ambiente local usado em testes: http://localhost:5520

## Modelo utilizado

Cada bug report deve conter:

- Identificação
- Ambiente
- Pré-condição
- Passos para reprodução
- Resultado esperado
- Resultado obtido
- Severidade
- Prioridade
- Evidência
- Status
