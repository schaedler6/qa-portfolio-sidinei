# BUG-003 — Cards da seção QA ainda não possuem link para projetos reais

## Identificação

| Campo | Informação |
|---|---|
| ID | BUG-003 |
| Título | Cards do Portfólio QA ainda não apontam para repositório GitHub |
| Projeto | SID.DEV.BR |
| Tipo | Melhoria / requisito pendente |
| Status | Em andamento |

## Ambiente

- Sistema operacional: Windows 10/11
- Navegador: Chrome
- URL local: http://localhost:5520
- Área afetada: Seção Portfólio QA

## Pré-condição

Seção Portfólio QA criada e visível no site.

## Passos para reprodução

1. Acessar o site.
2. Ir até a seção `Portfólio QA`.
3. Observar os cards `Testes Manuais`, `Bug Reports`, `Testes de API` e `Automação para QA`.
4. Verificar se há links para projetos reais.

## Resultado esperado

Cada card deve ter link para a respectiva pasta ou projeto no GitHub.

## Resultado obtido

Os cards apresentam conteúdo visual e tags, mas ainda precisam ser conectados ao repositório `qa-portfolio-sidinei`.

## Severidade

Baixa.

## Prioridade

Média.

## Evidência

A ser registrada após validação dos links.

## Observações

Não é defeito crítico. É uma etapa planejada do portfólio: primeiro criar o repositório, depois linkar os cards.
