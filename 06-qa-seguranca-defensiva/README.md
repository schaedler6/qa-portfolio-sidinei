# QA + Cibersegurança Defensiva

## Objetivo

Demonstrar como o olhar de QA pode contribuir para a segurança defensiva de sistemas, validando autenticação, permissões, mensagens de erro, exposição de dados, logs e boas práticas de proteção.

## Escopo

Este projeto é focado em validações defensivas, documentação, checklist e análise de riscos visíveis em aplicações web.

## Fora do escopo

- Exploração ofensiva.
- Invasão de sistemas.
- Coleta de credenciais.
- Ataques automatizados.
- Varreduras agressivas.
- Testes sem autorização.

## Competências demonstradas

- QA com foco defensivo
- Checklist de segurança básica
- Validação de permissões
- Validação de mensagens de erro
- Validação de exposição de dados
- Registro de evidências
- Documentação de riscos
- Comunicação técnica responsável
