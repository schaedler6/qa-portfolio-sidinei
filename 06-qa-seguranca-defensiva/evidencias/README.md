## Critério

Cada evidência deve indicar:

- item validado;
- data;
- ambiente;
- resultado observado;
- recomendação, se houver.

## Cuidado

Não salvar credenciais, tokens, chaves privadas ou dados pessoais sensíveis em evidências públicas.
